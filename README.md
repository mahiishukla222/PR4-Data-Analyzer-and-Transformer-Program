## 📌 Project Description

The Data Analyzer and Transformer Program is a Python-based project that allows users to input 1D and 2D arrays, analyze data, calculate statistics, filter values, and sort data.

This project demonstrates important Python concepts such as functions, recursion, lambda functions, map(), filter(), *args, **kwargs, and built-in functions.

## 🎯 Objectives

* To accept 1D and 2D array data from the user.
* To calculate the sum, minimum, maximum, and average of data.
* To calculate the factorial of a number using recursion.
* To filter data based on a threshold value.
* To sort data in ascending and descending order.
* To display dataset statistics using functions.

## 🛠️ Technologies Used

* Programming Language: Python
* Software: Python IDLE / VS Code
* Concepts: Lists, Functions, Recursion, Lambda, Map, Filter, *args, **kwargs

## ✨ Features

### 1. Input Data

Accepts data from the user in the form of a 1D array or a 2D array.

### 2. Display Data Summary

Displays:

* Total number of elements
* Minimum value
* Maximum value
* Sum of all values
* Average value

### 3. Calculate Factorial

Calculates the factorial of a number using recursion.

### 4. Filter Data by Threshold

Filters and displays values greater than or equal to the threshold entered by the user.

### 5. Sort Data

Sorts data in ascending or descending order.

### 6. Display Dataset Statistics

Displays the minimum, maximum, sum, and average using functions that return multiple values.

### 7. Exit Program

Allows the user to exit the program.
